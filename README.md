# Tag Graph Links（标签连线）

一个 Obsidian 插件：让**拥有相同标签**的笔记在关系图谱里自动连线。

比如文章 A 和文章 B 都有 `#色调` 标签，那么图谱里 A 和 B 之间就会出现一条线。这条线可以单独设置**颜色**，和普通的双向链接区分开。全局图谱（Graph View）和局部图谱（Local Graph）都生效。

## 安装（普通使用）

普通使用只需要 **3 个文件**：`main.js`、`manifest.json`、`styles.css`。

1. 在本仓库的 [Releases](../../releases) 页面下载这三个文件（或在仓库首页直接下载它们）。
2. 找到你的 Obsidian 库（vault）文件夹，进入隐藏目录 `.obsidian/plugins/`（没有 `plugins` 文件夹就新建一个）。
3. 在里面新建一个文件夹 `tag-graph-links`，把三个文件放进去，最终结构：

   ```
   你的库/.obsidian/plugins/tag-graph-links/
   ├── main.js
   ├── manifest.json
   └── styles.css
   ```

4. 打开 Obsidian → 设置 → 第三方插件（Community plugins）→ 如果「安全模式」开着就关掉。
5. 在「已安装插件」列表里找到 **Tag Graph Links**，打开开关。

> macOS 下 `.obsidian` 是隐藏文件夹，在访达里按 `Cmd + Shift + .` 显示隐藏文件。

## 使用

1. 打开关系图谱（左侧边栏图标，或命令面板搜「图谱」）。
2. 给若干笔记打上相同标签，比如都写 `#色调`。
3. 这些笔记之间就会出现标签连线。

### 图谱里的快捷开关

图谱左上角的控制面板（有「中心力」「连线力」那些滑块的面板）里会多出一个**链接图标**。点它会弹出一个小面板，上下两行：

- **标签连线**：开关，控制连线显示 / 隐藏。
- **颜色**：取色器，直接改连线颜色，图谱实时生效。

这个面板和设置页里的选项是双向同步的，改哪边都一样。

### 设置项（设置 → Tag Graph Links）

- **启用标签连线**：总开关。
- **连线颜色**：标签连线的颜色。
- **单标签最大连线数**：性能保护。某个标签下笔记太多时，两两连线数量会爆炸（n 篇笔记 = n×(n-1)/2 条边）。超过这个阈值的标签会被整体跳过。默认 200。
- **忽略的标签**：列在这里的标签不参与连线，逗号分隔。适合排除 `#笔记`、`#待办` 这种几乎每篇都有的标签。
- **调试日志**：在开发者控制台输出注入了多少边、跳过了哪些标签。

### 命令面板（Cmd / Ctrl + P）

- **刷新标签连线** —— 改了设置后图谱没变化时手动刷新。
- **开启 / 关闭标签连线** —— 快速开关。

## 工作原理与限制

Obsidian 官方插件 API 并不支持往关系图谱里添加自定义连线，也不支持给单条连线单独上色。本插件通过访问 Obsidian 的内部接口来实现：扫描全库标签，把共享同一标签的笔记两两连接，再持续为这些连线重新上色以区别于普通链接。

由于依赖内部接口，有两点需要知道：

- 连线功能比较稳定；颜色是「尽力而为」，在个别 Obsidian 版本上可能出现连线已画出但颜色未生效的情况。
- Obsidian 大版本升级后，插件可能需要跟着更新。

如果只是想让「共享标签的笔记产生关联」，这个功能很稳，颜色是锦上添花。

## 从源码构建（给想修改的人）

普通使用不需要这一节。如果你想改源码：

```bash
npm install      # 安装依赖
npm run build    # 构建出 main.js
npm run dev      # 开发模式，改动 main.ts 自动重新构建
```

源码在 `main.ts`，构建配置见 `esbuild.config.mjs`。
